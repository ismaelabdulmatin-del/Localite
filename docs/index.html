Localite

A local AWS-compatible endpoint for development and integration tests on Apple Silicon Macs. Runs in an isolated Linux VM—no Docker daemon required.

Download Localite for macOS

Apple Silicon · macOS 12 or later · 104 MB · Version 0.1.0

Interim distribution: this DMG is ad-hoc signed and not notarized. macOS may block the app or require manual approval in Privacy & Security. Only install it if you trust the source; verify the SHA-256 checksum on the release page. A Developer ID-signed and notarized release is not yet available.

Use your AWS tools

Start Localite, wait for the app to show Running · Moto AWS API, then point your SDK or CLI at http://localhost:4566. In the app, click Copy AWS env and paste the fake local credentials into the terminal where you run your code. The built-in Getting started guide includes Python and AWS CLI examples.

Verified service workflows

  • S3: bucket and object create/delete; put, get, and list objects.
  • SQS: queue create/delete; send, receive, and delete messages.
  • DynamoDB: table create/delete; item put/get/update/query/scan.
  • IAM: user create/get/list/delete.
  • STS: caller identity.

These workflows were exercised with boto3 against the bundled Moto server. This is a tested subset, not full AWS or LocalStack parity. The image tag is pinned as motoserver/moto:5.2.5; its installed Moto package metadata reports 5.2.5.dev0.

Know the limits

  • Emulator state resets when Localite stops; it is not durable storage.
  • Lambda code execution is not provided. Localite does not run your project code.
  • Your editor and app run on macOS and connect to the local endpoint. The selected workspace is isolated file storage, not a development container.
  • Use fake local credentials only. Do not send production workloads or credentials to this endpoint.
